# Privacy policy

Liberator Stream is a personal tool that streams a Bitcoin price dashboard to
the owner's own YouTube channel, "The Bitcoin Liberator".

## What it accesses

When the channel owner signs in with Google, the app asks for permission to
manage that channel's YouTube account. It uses that permission for one thing:
reading the channel's currently active live broadcast and updating its title
with the current Bitcoin price, every few minutes.

## What it stores

The sign-in token is stored only on the owner's own computer, in a local
configuration file that is never uploaded or shared. The app keeps no other
data about the account, its viewers, or anyone else.

## What it shares

Nothing. No data is sold, shared, or sent anywhere other than Google's own
YouTube API.

## Removing access

Access can be revoked at any time from the Google account's security settings
(myaccount.google.com/permissions).
